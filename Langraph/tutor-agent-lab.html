Caveats: one run per tool, one free model that returned 429 rate-limit errors often, and the LangGraph run times were not recorded.

1. How much control did you have over each step?
  • LangGraph, the most. Every node, state field, edge, retry loop and validation rule is in your code. The injection never reached the answer node because Classify routes first.
  • n8n, high and visual. You set each prompt, Switch rule, retry count and wait time per node. You control less of how the model call itself is made.
  • Hermes, the least. You give it goals and a skill, and the agent decides how to reason and which tools to use. It treated the setup message as a question, and it wrote the poem until the skill was loaded.
2. Which was fastest to build, and which was easiest to modify and debug?
  • Fastest to start: Hermes. After the install you just talk to it. Fastest to a working pipeline: n8n, with no code and no installs.
  • Easiest to debug: n8n. Each node shows its input and output, so you could see exactly where the 429 hit. Our two n8n bugs (a field name left in Expression mode, and a model that defaulted to a paid one) were visible on the canvas.
  • Easiest to modify: n8n for small changes, LangGraph for structural changes. Hermes is hardest, because the same instructions can give different behavior from one session to the next.
3. Which gave the most correct and consistent results?
  • LangGraph and n8n tied at 5 / 5, including the injection input, because the label decides the route before any answer is written.
  • Hermes scored 4 / 5. It handled normal and unclear inputs, but followed the “write a poem” instruction until the skill was explicitly loaded, and failed again in a fresh session.
  • All three hit 429 errors. LangGraph used a retry loop we wrote, n8n used one setting, and Hermes retried three times and then asked for /retry.
  • Small sample: five inputs, one free model, one run each.
4. Which would you choose for production, business automation and a personal assistant?
  • Production: LangGraph. Routing is explicit, testable and versioned in code. A free model is not production-grade, so you would also pay for reliable capacity.
  • Business automation: n8n. Triggers, integrations, retries and a saved result table are built in, and non-programmers can read and change the workflow.
  • Personal assistant: Hermes. Persistent memory, skills and tools make it flexible. Do not rely on its skill rules for safety, because they did not hold across sessions.
